# 群文字冒险的开启与参与

游戏已接入现有 Tulpa 群助手的同一接收器。默认关闭，由目标群的群主开启，
不增加QQ登录，不启动第二个NapCat，不向群发送部署公告。

在 QQ 中实际选中机器人进行 @，不要只输入“@机器人”几个字。

| 谁来发送 | 群消息 | 作用 |
|---|---|---|
| 群主 | @机器人 游戏开启 | 开放当前群的游戏 |
| 任意群友 | @机器人 游戏帮助 | 查看命令和规则 |
| 任意群友 | @机器人 冒险 | 查看共享事件；没有事件时生成 |
| 任意群友 | @机器人 行动 用藤蔓把巨魔绑住，再用蘑菇遮挡它的视线 | 提交自己的完整方案 |
| 任意群友 | @机器人 游戏状态 | 查看自己的等级、属性和群事件进度 |
| 任意群友 | @机器人 游戏背包 | 查看物品 |
| 任意群友 | @机器人 游戏重试 | 显式恢复生成/评估失败的请求 |
| 100级群友 | @机器人 挑战最终Boss | 开始个人Boss挑战；接着使用“行动 方案” |
| 群主 | @机器人 游戏关闭 | 暂停游戏，保留进度 |

群友可以自由讨论，只有明确 @机器人 的游戏命令才进入游戏。正文里提到技术问题、
失败或报错不会为游戏创建Bug；游戏也不占个人5小时100条闲聊次数。
没有@机器人、@其他人的消息都不会被当成游戏命令。

每天北京时间零点刷新群额度，每群总共3个事件，首次生成计入3个。
有人成功就升级、获得物品并刷新下一事件；第三个成功后等待次日。
失败只清零挑战者的等级与背包，事件保留，允许任何人继续提交新方案，无次数限制。
次日未解决事件过期，不发奖励、不扣不参与者等级；下次“冒险”按需生成新事件。
最终Boss独立于群额度，仍需100级，可在群当天3事件已通过后挑战。

同一时刻共享事件只能处理一个方案，其他方案需稍后重新提交，避免重复结算。
重复投递同一QQ消息不会发两次奖励。“无限试错”指游戏规则没有尝试次数上限，
模型费用仍受预算限制。

## 费用与数据

游戏事件生成、方案评估、结局生成和发送前审核都使用生产 `SupportBudget`，
计费类型为 `adventure`，与技术问答和闲聊共同分享固定的每天5元池。
游戏不另开5元池，也不受闲聊3元子额度限制；总池耗尽后模型请求暂停。
未知费用继续保留预留，不自动重复付费请求。次日恢复预算，但失败请求需显式重试。

群开关、共享事件、个人状态和幂等记录都保存在 `data/asmr-support.sqlite3`。
群键来自实际QQ群的conversation_id，个人键为机器人账号+用户QQ，正文不能指定他人身份。
CLI测试库与生产QQ勇者隔离，不迁入试玩奖励。

目前沿用现有群助手只服务当前授权群的范围；游戏不会自动接入其他群。
